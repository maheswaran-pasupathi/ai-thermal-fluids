# Contributing

This portfolio is also a community learning space for CFD/thermal engineers exploring AI/ML. Contributions from beginners and experienced practitioners are both welcome.

## Ways to contribute

- **Ask or answer in Discussions** — physics questions, ML questions, "why did you choose this method" questions all belong here.
- **Suggest a dataset** — open an Issue with a link and a one-line description of what physical problem it could support.
- **Suggest or critique a method** — if a project's ML approach looks wrong, naive, or could be done better, say so in an Issue. Physical correctness matters more than model sophistication here.
- **Submit your own take** — fork a project folder, try a different method on the same dataset, and open a PR with your result and a short writeup. Alternative approaches to the same problem are especially welcome.
- **Fix errors** — typos, broken links, incorrect physics explanations, bugs in notebooks.

## Ground rules

- Every project keeps physical interpretation front and center — a result with no engineering explanation isn't useful here.
- Cite your sources — datasets, papers, prior work.
- No proprietary/employer data or code from any contributor.
- Be direct but constructive in Discussions/Issues — this is a learning space, not a showcase of finished expertise.

## Getting started

1. Pick a project folder under `projects/`.
2. Read its README for the engineering problem, dataset, and current status.
3. Open an Issue first if you're planning a nontrivial contribution, so effort isn't duplicated.
