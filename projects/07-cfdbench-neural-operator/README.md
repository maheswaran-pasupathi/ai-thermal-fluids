# Project 07 — Scientific ML / Neural Operators

**Status: ⚪ Planned**

## Engineering problem
Demonstrate hands-on use of a neural operator (e.g. Fourier Neural Operator) to predict full CFD solution fields (pressure, velocity) for a canonical problem, as exposure to the scientific-ML methods increasingly used for PDE surrogate modeling.

## Physics baseline
Canonical CFD problem with geometry/boundary-condition inputs and pressure/velocity solution-field outputs.

## Dataset
CFDBench — https://github.com/luo-yining/CFDBench

## Method
Fourier Neural Operator (or equivalent) mapping geometry/BC to solution fields, compared against ground-truth CFD with an error field.
