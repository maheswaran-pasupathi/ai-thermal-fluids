# Project 02 — Spray & Combustion ML

**Status: ⚪ Planned**

## Engineering problem
Predict combustion-relevant spray KPIs (ignition delay, liquid/vapor penetration, lift-off length) from injection and ambient conditions, with physically interpretable feature importance.

## Physics baseline
Injection pressure, ambient temperature/density, oxygen concentration, nozzle diameter, and their effect on spray/combustion development.

## Dataset
Engine Combustion Network (ECN) — diesel/gasoline spray-combustion experimental data.
- https://ecn.sandia.gov/cfd-data-search/
- https://ecn.sandia.gov/diesel-spray-combustion/experimental-data-search/
- https://ecn.sandia.gov/gasoline-data-search/

## Method
Random Forest / XGBoost regression + SHAP for physical interpretation of feature importance and plausibility checks against known combustion trends.
