# Project 05 — Electronics Hotspot Prediction

**Status: ⚪ Planned**

## Engineering problem
Predict maximum temperature and/or the full temperature map from power distribution, heat-source layout, and cooling condition — a hotspot predictor transferable to CPU/GPU, ECU, power-electronics and battery-electronics cooling.

## Physics baseline
Conduction/convection from discrete heat sources on a board/package, airflow or coolant condition, material properties.

## Dataset
Commercial processor thermal-map dataset.
- https://github.com/sheldonucr/commercial_thermal_map_dataset
- https://sheldonucr.github.io/commercial_thermal_map_dataset/

## Method
CNN mapping power/layout input to spatial temperature-map output.
