# Project 04 — Vehicle Aerodynamics AI

**Status: ⚪ Planned**

## Engineering problem
Predict drag coefficient (Cd) from vehicle geometry descriptors, and explain which geometric features drive drag — useful as a fast screening tool ahead of full CFD.

## Physics baseline
External aerodynamics, geometry-drag relationships, design-space screening.

## Dataset
DrivAerNet++ — https://github.com/roharon/drivaernet

## Method
Geometry descriptors → XGBoost/Random Forest regression for Cd, with SHAP/feature-importance analysis for explainability rather than a full 3-D deep-learning approach.
